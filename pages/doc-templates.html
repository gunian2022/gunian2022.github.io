DOCUMENT STUDIO / 03

先立文档，再让 Agent 动手。

一套固定的 docs 目录 + AGENT.md：design 说清页面有什么、为什么有；spec 把颜色、字号、按钮、弹窗、滚动条钉成可执行标准；tasks 拆成能勾选的小任务。选文件 → 复制骨架 → 贴给 AI，不用每次重讲一遍要求。

页面规模11–14 个位置含全局设计规范双端同一套令牌只读 · 复制即用

ROLES

三份文档，各管一件事

同一个页面在三份文件里三副面孔，缺一份就算没写完。编号 B / C / A / F 三处必须对得上：design 里是 B-01，spec 与 tasks 里也必须叫 B-01。

DESIGN / 有什么

页面设计

字段清单、板块、组件、按钮、页面状态、业务逻辑。只回答「为什么需要它」，不写像素和色值。

  • 每个字段写清「谁在什么情况下用」
  • 写不出场景的元素直接删掉
  • 字段分两表：清单 + 场景与理由

SPEC / 做成什么样

规范与验收

全局一份设计规范（颜色令牌、字号阶梯、按钮、表单、表格、弹层、滚动条），用户端与管理端共用同一套；页面一份约束与 AC 验收。

  • 颜色给到十六进制编号与禁用场景
  • 弹窗与按钮下拉框都给到圆角 / 阴影 / 关闭方式
  • 每条验收都能判定通过或失败

TASKS / 怎么拆

任务清单

把 design + spec 拆成每页固定 12 条任务，每条写清做什么、改哪些文件、怎么算做完。

  • 一条任务半天内做完、改动 ≤3 个文件
  • 标准包 T-001 到 T-012，增删要写原因
  • 每条任务绑定一个 AC 验收编号
